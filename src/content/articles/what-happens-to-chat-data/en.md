The question “what happens to what I type into ChatGPT?” does not have one single answer because several mechanisms sit behind the same interface. The key is to separate chat history, memory, and possible use of content for model improvement.

## Chat history

History lets you return to previous conversations. Saving a conversation in history is not the same as saving information in memory.

## Memory

Memory can preserve selected information for future conversations. It is distinct from history and model training.

## Model improvement

Consumer ChatGPT provides controls related to whether new conversations may be used to improve models. Policies can change, so current official documentation should be checked when privacy decisions depend on the details.

## Temporary Chat

Temporary Chat is designed for conversations that should not behave like normal saved chats with persistent history or newly created memories.

## Confidential information

A useful rule remains:

> do not put information into an external system if you are not comfortable with that information being processed there.

This includes passwords, company secrets, credentials, or unnecessary personal data.

## Apps and external services

When a model uses external applications or integrations, some data may be passed to another provider under that service's own rules.

## The key distinction

```text
history
≠ memory
≠ model improvement
≠ external integrations
```

Treating these mechanisms as one thing causes many misunderstandings.
